📁 UPLOAD EXCEL STOK
Gunakan format file Stok_Kecap_Sambal_….xlsx. Boleh upload beberapa file (per bulan), data digabung otomatis. Jika bulan yang sama diupload lagi, data bulan itu diganti. Sel stok yang diisi manual (kuning) ikut terbaca.
🗑 HAPUS DATA PER BULAN
Konfirmasi akan muncul sebelum data dihapus. Penghapusan ikut tersinkron ke cloud.
➕ BUAT BULAN BARU
Daftar produk dan saldo awal otomatis diambil dari stok akhir bulan sebelumnya (jika ada).
📤 EXPORT
Hasil export memakai rumus yang sama seperti file asli, termasuk sel kuning penyesuaian stok.
☁️ CLOUD (Supabase)
Memakai database yang sama dengan Data Penjualan (tabel app_sync, baris stok_kecap_sambal), jadi data penjualan dan stok minyak tidak tersentuh.
Mode lokal
Stok = stok hari sebelumnya + MSK − KLR (untuk CABE GNG 600 REF: − BD − REF). Isi MSK / KLR per hari, stok & total terhitung otomatis. Sel kuning = penyesuaian stok manual: ketik angka di kolom STOK untuk mengganti hitungan hari itu, kosongkan untuk kembali otomatis. Produk bertanda * tidak dijumlahkan ke kolom STOCK (sesuai file asli).
