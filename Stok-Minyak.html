Stok Minyak
☰ MENU
📁 UPLOAD EXCEL STOK
Gunakan format file Stok_Minyak_….xlsx (kolom MSK, KLR, STOK SFA per botol). Boleh upload beberapa file (per bulan), data digabung otomatis. Jika bulan yang sama diupload lagi, data bulan itu diganti.
🗑 HAPUS DATA PER BULAN
Konfirmasi akan muncul sebelum data dihapus. Penghapusan ikut tersinkron ke cloud.
➕ BUAT BULAN BARU
Saldo awal otomatis diambil dari stok akhir bulan sebelumnya (jika ada).
📤 EXPORT
Hasil export memakai rumus yang sama seperti file asli (stok = stok kemarin + MSK − KLR).
☁️ CLOUD (Supabase)
Memakai database yang sama dengan Data Penjualan (tabel app_sync, baris stok_minyak), jadi data penjualan tidak tersentuh.
Mode lokal
Stok SFA = stok hari sebelumnya + MSK − KLR. Isi kolom MSK (masuk) dan KLR (keluar) per hari; stok & total otomatis terhitung. Saldo awal diisi manual (kotak berbingkai). Perubahan tersimpan otomatis di perangkat dan dikirim ke cloud.
